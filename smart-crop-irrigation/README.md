# Smart Crop Water Management & Irrigation Prediction System

## Problem Statement
Traditional irrigation systems often lead to water wastage and sub-optimal crop yields due to generalized scheduling. A smart, data-driven approach is required to optimize water usage based on real-time environmental conditions.

## Objectives
1. Simulate real-time environmental sensing using Wokwi ESP32.
2. Develop a Machine Learning model to predict irrigation needs based on sensor data.
3. Build a FastAPI backend to serve predictions and manage IoT data.
4. Create a React dashboard to visualize sensor data, ML insights, and control status.
5. Implement a safety layer combining ML predictions with physical thresholds.

## System Architecture

**Data Flow:**
```text
Wokwi
  ↓
ESP32
  ↓
Sensor readings (Soil Moisture, Temp, Humidity, Light)
  ↓
IoT transport
  ↓
Backend / IoT data layer
  ↓
Data storage
  ↓
ML prediction
  ↓
Irrigation decision (ML Prediction + Safety Thresholds)
  ↓
Dashboard
  ↓
Pump control (Simulated Relay)
```

## Technology Stack
- **IoT Simulation**: Wokwi, ESP32, C++
- **Backend**: Python, FastAPI, Pydantic
- **Machine Learning**: Scikit-Learn, Pandas (Models: Logistic Regression, Decision Tree, Random Forest, XGBoost)
- **Frontend**: React, Vite, Tailwind CSS, Recharts

## Folder Structure
- `wokwi/`: ESP32 simulation files and circuit diagram.
- `data/`: Datasets (external training data and IoT test data).
- `ml/`: Machine Learning pipeline (notebooks, source code, models).
- `backend/`: FastAPI server, routes, and schemas.
- `dashboard/`: React Vite frontend application.
- `docs/`: Architecture diagrams and screenshots.

## Data Distinctions
- **Training data**: External real agricultural dataset (used for training the ML model).
- **IoT testing data**: Data generated by Wokwi (used for testing the prediction pipeline).
These will not be mixed during the initial model training phase.

## ML Safety Layer
The final irrigation controller will not blindly trust the ML prediction.
The logic will be:
`Prediction == irrigation_required AND soil_moisture < safety_threshold`
